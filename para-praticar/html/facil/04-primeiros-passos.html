Primeiros passos para criação da primeira página HTML

Nesta página, serão apresentados os primeiros passos para compreender a criação e a abertura de páginas web locais. Você conhecerá a estrutura básica de um documento HTML, a função das principais tags e como os arquivos HTML são interpretados pelos navegadores, desenvolvendo uma base para iniciar seus estudos em desenvolvimento web.

Passo a passo

  1. Abrir VsCode
  2. Criar um novo folder
  3. Criar um novo arquivo e nomeá-lo de "primeira-pagina.html"
  4. Escrever a boilerplate básica, apenas digite "!" e pressione tab
  5. Alterar o elemento title da boilerplate para o título da página
  6. Escrever um título dentro de uma tag h1
  7. Escreva um pequeno parágrafo dentro de um elemento p
  8. Instale a extensão live
  9. Pressione Alt + L + Alt + O, isso abrirá sua página no seu navegador principal
