Sobre a matéria de Front-End Dev

A disciplina Desenvolvimento Front-End para Web tem como objetivo ensinar os fundamentos da criação de páginas e interfaces web, utilizando tecnologias como HTML, CSS e JavaScript. Durante as atividades, os alunos aprendem a estruturar conteúdos, organizar elementos e desenvolver páginas acessíveis, funcionais e visualmente atrativas.

Conteúdo da semana

  • Bootstrap
  • Versionamento GitHub
  • Resumão para prova

Etapas de Estudo

  1. Organizar tudo que foi feito no semestre
  2. Fazer resumo sobre HTML
  3. Fazer resumo sobre CSS
  4. Fazer resumo sobre JS
  5. Realizar exercícios para praticar

Projetos realizados

Projeto 1 - HTML

Desenvolvimento de uma página web utilizando HTML, aplicando tags semânticas, títulos, parágrafos, listas, links, imagens e organização de conteúdo.

Projeto 2 - CSS

Criação e estilização de páginas web com CSS, trabalhando cores, fontes, espaçamentos, bordas, layouts e organização visual dos elementos.

Projeto 3 - JS

Desenvolvimento de funcionalidades interativas utilizando JavaScript, incluindo eventos, variáveis, funções e manipulação de elementos HTML.

Dicas de estudo

Para acompanhar a disciplina, é importante praticar a criação de páginas HTML, explorar recursos de CSS e desenvolver pequenos projetos utilizando JavaScript.

Ferramentas recomendadas

  • Visual Studio Code
  • Google Chrome
  • Documentação MDN Web Docs

Dica

Pratique diariamente e teste diferentes elementos para aprimorar suas habilidades em desenvolvimento web.
