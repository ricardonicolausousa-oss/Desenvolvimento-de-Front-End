# Descubra seu caminho no Front-End

Projeto 3 — Painel Interativo com JavaScript.

## Integrantes
- Nome do aluno(a)

## Descrição
O visitante informa o nome, escolhe uma área (HTML, CSS ou JavaScript) e recebe uma orientação personalizada. Há também um botão para alternar entre tema claro e escuro.

## Tecnologias
HTML5, CSS3 e JavaScript.

## Como usar
Abra o arquivo `index.html` no navegador.
